baixar_acordao

courts.tjms.client.TJMSScraper.baixar_acordao(
    cd_acordao,
    cd_foro,
    diretorio=None,
)

Baixa o PDF do inteiro teor do acórdão de uma linha do cjsg.

Um pedido por acórdão, sem login e sem captcha. Devolve o PDF como o tribunal o publica; a extração de texto fica com quem usa a biblioteca.

Parameters

Name Type Description Default
cd_acordao str Coluna cd_acordao do cjsg. required
cd_foro str Coluna cd_foro do cjsg. required
diretorio str | None Pasta de destino. Default download_path. O PDF vai para <diretorio>/acordaos/<cd_acordao>.pdf. None

Raises

Name Type Description
EntradaInvalidaError Código vazio ou que não é só dígitos. Herda de ValueError.
DocumentoNaoPdfError getArquivo.do respondeu sem %PDF (página “Arquivo não localizado”, captcha ou login); nada é gravado.

Returns

Name Type Description
str Caminho do PDF gravado.

Exemplo

>>> import juscraper as jus
>>> tjms = jus.scraper("tjms")
>>> df = tjms.cjsg("dano moral", paginas=1)
>>> caminho = tjms.baixar_acordao(df.cd_acordao[0], df.cd_foro[0])

Baixa o PDF da sentença de uma linha do cjpg.

Sem login e sem captcha. Devolve o PDF como o tribunal o publica; a extração de texto fica com quem usa a biblioteca (o cjpg já traz o texto na coluna decisao; o PDF guarda a formatação e as assinaturas).

Parameters

Name Type Description Default

cd_foro str Coluna cd_foro do cjpg. required
cd_documento str Coluna cd_documento do cjpg. required

diretorio str | None Pasta de destino. Default download_path. O PDF vai para <diretorio>/sentencas/<cd_processo>_<cd_documento>.pdf. None

Raises

Name Type Description
EntradaInvalidaError Código vazio ou fora do formato do eSAJ. Herda de ValueError.
PastaInesperadaError A página da pasta não veio.
DocumentoNaoPdfError getPDF.do respondeu sem %PDF.

Returns

Name Type Description
str Caminho do PDF gravado.

Exemplo

>>> import juscraper as jus
>>> tjsp = jus.scraper("tjsp")

>>> linha = df.iloc[0]
>>> caminho = tjsp.baixar_sentenca(linha.cd_processo, linha.cd_foro, linha.cd_documento, linha.nm_alias)

cjpg

courts.tjms.client.TJMSScraper.cjpg(pesquisa='', paginas=None, **kwargs)

Pesquisa jurisprudencia de primeiro grau do tribunal (CJPG).

Delega para cjpg_download + cjpg_parse e remove o diretorio temporario antes de retornar. Diferente do CJSG, aqui pesquisa aceita string vazia — o usuario pode buscar so por filtros (ex.: todas as decisoes de uma vara especifica num intervalo de datas).

Parameters

Name Type Description Default
pesquisa str Termo livre buscado na decisao. Default "" (sem termo). No TJSP, limite de 120 caracteres (raises QueryTooLongError). ''
paginas int | list | range | None Paginas 1-based; None baixa todas. Default None. None
**kwargs Any Filtros aceitos por InputCJPGEsaj (todos opcionais; None = sem filtro): * classe (int | str | list[int | str]): ID(s) internos de classe processual. Backend: classeTreeSelection.values (CSV). * assunto (int | str | list[int | str]): ID(s) internos de assunto. Backend: assuntoTreeSelection.values (CSV). * vara (int | str | list[int | str]): ID(s) internos de vara, no formato em arvore do eSAJ (ex.: "1-1-1"). Backend: varasTreeSelection.values (CSV). * id_processo (str): Numero CNJ formatado para filtrar uma instancia especifica. Normalizado via clean_cnj antes do envio. * data_julgamento_inicio / data_julgamento_fim (str | date | datetime): Intervalo de julgamento. Aceita DD/MM/AAAA, DD-MM-AAAA, AAAA-MM-DD, AAAA/MM/DD, date ou datetime. * auto_chunk (bool): Default True. Quando o intervalo data_julgamento_* excede 1 ano, divide internamente em janelas, baixa cada uma e concatena com dedup por id_processo. Veja a secao “Auto-chunking” abaixo. * count_only (bool): Default False. Se True, faz so o GET inicial, extrai o total de resultados via cjpg_n_results e retorna int em vez de pd.DataFrame. Util pra estimar wall-clock antes de coleta longa (issue #92). Com auto_chunk=True + janela > 1 ano, itera janelas disjuntas e soma — soma bruta (sem dedup por id_processo). paginas e ignorado (emite UserWarning). {}

Aliases deprecados (popados com DeprecationWarning antes do pydantic):

* ``query`` / ``termo`` -> ``pesquisa``
* ``classes`` -> ``classe``
* ``assuntos`` -> ``assunto``
* ``varas`` -> ``vara``
* ``data_inicio`` / ``data_fim`` -> ``data_julgamento_inicio`` / ``_fim``
* ``data_julgamento_de`` / ``_ate`` -> ``data_julgamento_inicio`` / ``_fim``

Raises

Name Type Description
TypeError Quando um kwarg desconhecido e passado (via raise_on_extra_kwargs).
ValidationError Quando um filtro tem formato invalido.
QueryTooLongError No TJSP, quando pesquisa excede 120 chars.
ValueError Quando classe e classes (ou par equivalente) sao passados simultaneamente.
ColetaParcialError Quando parte das paginas baixadas nao pode ser lida; .resultado traz as paginas lidas. Ver cjpg_parse_manager.

Returns

Name Type Description
pd.DataFrame | int Resultados parseados (colunas conforme OutputCJPGEsaj — id_processo, cd_processo e campos extras emitidos pelo parser via extra='allow' — classe, assunto, magistrado, comarca, foro, vara, data_disponibilizacao, decisao); int com o total de resultados quando count_only=True.

Exemplo

>>> import juscraper as jus
>>> tjsp = jus.scraper("tjsp")
>>> # Busca textual + filtro de vara:
>>> df = tjsp.cjpg("dano moral", paginas=range(1, 3),
...                vara="1-1-1")
>>> # So filtros (sem termo) — IDs como int ou list:
>>> df = tjsp.cjpg(paginas=1, classe=12728, assunto=[3607, 5885],
...                data_julgamento_inicio="01/01/2024",
...                data_julgamento_fim="31/03/2024")
>>> # Estimativa pre-scraping (issue #92):
>>> n = tjsp.cjpg("dano moral", count_only=True)

See Also

InputCJPGEsaj — schema pydantic e a fonte da verdade dos filtros aceitos.

Auto-chunking (issue #130): Se auto_chunk=True (default herdado de AutoChunkMixin) e o intervalo data_julgamento_* exceder 1 ano, a busca e dividida em janelas internas, baixadas e concatenadas com dedup por id_processo. Janela que falha levanta ColetaParcialError, com as janelas que passaram em .resultado. auto_chunk=True + paginas != None em janela > 1 ano e ValueError.

courts.tjms.client.TJMSScraper.cjpg_download(
    pesquisa='',
    paginas=None,
    diretorio=None,
    **kwargs,

Baixa as paginas HTML brutas do CJPG (sem parsear).

Delega a normalizacao de pesquisa ao pipeline (via consume_pesquisa_aliases=True + nullable_pesquisa=True — CJPG admite busca aberta com pesquisa=""). Roda o hook _validate_pesquisa sobre o valor ja resolvido (apos consumir query/termo), para que o QueryTooLongError do TJSP propague mesmo quando o alias trouxe a string longa. Aceita os mesmos filtros de cjpg; veja la a lista completa.

Parameters

paginas int | list | range | None Paginas 1-based; None baixa todas. Default None. None
diretorio str | None Sobrescreve download_path para esta unica chamada. Default None. None
**kwargs Any Mesmos filtros aceitos por cjpg (validados por InputCJPGEsaj). {}

Raises

Name Type Description
TypeError Quando um kwarg desconhecido e passado.
ValidationError Quando um filtro tem formato invalido.
QueryTooLongError No TJSP, quando pesquisa (ou alias resolvido) excede 120 chars.
ValueError Quando o usuario passa um alias deprecado e o nome canonico simultaneamente (ex.: classe e classes; refs #232).

Returns

Name Type Description
str Caminho do diretorio onde os HTMLs foram salvos.

cjsg

courts.tjms.client.TJMSScraper.cjsg(pesquisa, paginas=None, **kwargs)

Pesquisa jurisprudencia de segundo grau do tribunal (CJSG).

Delega para cjsg_download + cjsg_parse e remove o diretorio temporario antes de retornar.

Parameters

Name Type Description Default
pesquisa str Termo livre buscado no acordao/ementa. required
paginas int | list | range | None Paginas 1-based; None baixa todas. Default None. None
**kwargs Any Filtros aceitos pelo schema configurado em INPUT_CJSG (default InputCJSGEsajPuro, herdado por TJAC/TJAL/TJAM/TJCE/TJMS). Subclasses podem trocar INPUT_CJSG e mudar a lista de filtros — TJSP usa InputCJSGTJSP. Filtros do schema padrao (todos opcionais; None = sem filtro): * ementa (str): Termo buscado especificamente na ementa. * numero_recurso (str): Numero do recurso. * classe (int | str | list[int | str]): ID(s) interno(s) da classe processual. Backend: classesTreeSelection.values (CSV). * assunto (int | str | list[int | str]): ID(s) interno(s) do assunto. Backend: assuntosTreeSelection.values (CSV). * comarca (int | str): ID interno da comarca. Backend: cdComarca (single-value, nao aceita lista). * orgao_julgador (int | str | list[int | str]): ID(s) interno(s) do orgao julgador. Backend: secoesTreeSelection.values (CSV). * origem (Literal[“T”, “R”]): "T" (segundo grau, default) ou "R" (colegio recursal). * tipo_decisao (Literal[“acordao”, “monocratica”]): Default "acordao". * data_julgamento_inicio / data_julgamento_fim (str | date | datetime): Intervalo de julgamento. Aceita DD/MM/AAAA, DD-MM-AAAA, AAAA-MM-DD, AAAA/MM/DD, date ou datetime. * data_publicacao_inicio / data_publicacao_fim (str | date | datetime): Intervalo de publicacao, nos mesmos formatos. * auto_chunk (bool): Default True. Quando o intervalo data_julgamento_* excede 1 ano, divide internamente em janelas, baixa cada uma e concatena com dedup por cd_acordao. Veja a secao “Auto-chunking” abaixo. * count_only (bool): Default False. Se True, faz so a chamada inicial da pagina 1, extrai o total de resultados via cjsg_n_results e retorna int em vez de pd.DataFrame. Util pra estimar wall-clock antes de uma coleta longa (issue #92). Com auto_chunk=True + janela > 1 ano, itera janelas disjuntas e soma — soma bruta (sem dedup por cd_acordao), pode divergir ligeiramente de len(cjsg(...)) quando ha acordaos republicados. paginas e ignorado (emite UserWarning). {}

Aliases deprecados (popados com DeprecationWarning antes do pydantic):

* ``query`` / ``termo`` -> ``pesquisa``
* ``data_inicio`` / ``data_fim`` -> ``data_julgamento_inicio`` / ``_fim``
* ``data_julgamento_de`` / ``_ate`` -> ``data_julgamento_inicio`` / ``_fim``
* ``data_publicacao_de`` / ``_ate`` -> ``data_publicacao_inicio`` / ``_fim``

Raises

Name Type Description
TypeError Quando um kwarg desconhecido e passado (via raise_on_extra_kwargs).
ValidationError Quando um filtro tem formato invalido.

Returns

Name Type Description
pd.DataFrame | int Resultados parseados (colunas conforme OutputCJSGEsaj — processo, ementa, relator via mixin, data_publicacao via mixin, cd_acordao, cd_foro); int com o total de resultados quando count_only=True.

Exemplo

>>> import juscraper as jus
>>> tjac = jus.scraper("tjac")
>>> df = tjac.cjsg("dano moral", paginas=range(1, 3),
...                data_julgamento_inicio="01/01/2024")
>>> # Estimativa pre-scraping (issue #92):
>>> n = tjac.cjsg("dano moral", count_only=True)

See also

InputCJSGEsajPuro (ou InputCJSGTJSP) — schema pydantic e a fonte da verdade dos filtros aceitos.

Auto-chunking (issue #130): Se auto_chunk=True (default herdado de AutoChunkMixin) e o intervalo data_julgamento_* exceder 1 ano, a busca e dividida em janelas internas, baixadas e concatenadas com dedup por cd_acordao. Janela que falha levanta ColetaParcialError, com as janelas que passaram em .resultado. auto_chunk=True + paginas != None em janela > 1 ano e ValueError. Para o comportamento estrito antigo (ValueError em janelas longas), passe auto_chunk=False.
