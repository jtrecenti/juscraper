courts.tse.client.TSEScraper

courts.tse.client.TSEScraper(
    sleep_time=INTERVALO_INTEIRO_TEOR,
    download_path=None,
    verbose=0,
    politica=None,
)

Raspador do Tribunal Superior Eleitoral.

Cobre o que o portal de jurisprudência entrega sem captcha: o PDF do inteiro teor pelo código da decisão, do TSE ou de um TRE, e os catálogos do formulário (classes, relatores, eleições e normas), do TSE e dos TREs. A busca de jurisprudência exige um token de captcha validado no servidor, que requisições HTTP puras não têm como gerar, e não está implementada; ver cjsg.

Parameters

Name Type Description Default
sleep_time float Segundos entre dois pedidos de inteiro teor (default 10). O serviço recusa pedidos mais próximos com “Excesso de requisições”. O intervalo conta entre todas as instâncias do processo, porque o serviço não distingue uma da outra; cada pedido espera o sleep_time da instância que o faz. INTERVALO_INTEIRO_TEOR
download_path str | None Pasta padrão dos PDFs. None usa um diretório temporário. None
verbose int Nível de detalhe do log. 0
politica Mapping[str, Mapping[str, Any]] | None Ajustes dos perfis HTTP catalogo e inteiro_teor, por campo de RequestPolicy. None

baixar_inteiro_teor

courts.tse.client.TSEScraper.baixar_inteiro_teor(codigo_decisao, diretorio=None)

Baixa o PDF do inteiro teor de uma decisão do TSE ou de um TRE.

Um pedido por decisão, sem login e sem captcha. Devolve o PDF como o tribunal o publica; a extração de texto fica com quem usa a biblioteca. O serviço é o mesmo para o TSE e os TREs, e o código basta para achar a decisão. Pedidos seguidos guardam sleep_time entre si, também entre instâncias diferentes do raspador no mesmo processo; processos diferentes não se enxergam.

Parameters

Name Type Description Default
codigo_decisao int | str Código da decisão no portal (o codigoDecisao da busca, que também aparece no fim do link de inteiro teor, .../rest/download/pdf/<codigo>). required
diretorio str | None Pasta de destino. Default download_path. O PDF vai para <diretorio>/inteiro_teor/<codigo_decisao>.pdf. None

Raises

Name Type Description
CodigoInvalidoError Código que não é inteiro nem texto só de dígitos, antes de qualquer pedido. Herda de ValueError.
LimiteDeRequisicoesError O serviço recusou o pedido por excesso de requisições; nada é gravado. Herda de InteiroTeorIndisponivelError.
InteiroTeorIndisponivelError O serviço respondeu sem PDF, como faz com código que não existe; nada é gravado. As três exceções ficam em juscraper.courts.tse.download.

Returns

Name Type Description
str Caminho do PDF gravado.

Exemplo

>>> import juscraper as jus
>>> tse = jus.scraper("tse")
>>> caminho = tse.baixar_inteiro_teor(3522031)

baixar_inteiros_teores

courts.tse.client.TSEScraper.baixar_inteiros_teores(
    codigos_decisao,
    diretorio=None,
)

Baixa o PDF do inteiro teor de várias decisões, uma linha por código.

Chama baixar_inteiro_teor para cada código, na ordem da entrada, com sleep_time entre os pedidos: são 10 s por decisão no default. A falha de uma decisão não interrompe o lote; duas recusas seguidas por excesso de requisições, sim, e as linhas seguintes saem limite_de_requisicoes sem pedido. O erro ao gravar um PDF também encerra o lote: a linha e as seguintes saem erro_de_gravacao.

Parameters

Name Type Description Default
codigos_decisao Iterable[int | str] Códigos das decisões, como em baixar_inteiro_teor; uma lista ou a coluna de um DataFrame. Código repetido é baixado de novo. required
diretorio str | None Pasta de destino, como em baixar_inteiro_teor. None

Raises

Name Type Description
TypeError codigos_decisao é um código só (texto ou inteiro), e não uma coleção deles.

Returns

Name Type Description
pd.DataFrame Colunas codigo_decisao (como veio na entrada), caminho_inteiro_teor (None na falha) e motivo_falha: None no sucesso, nao_pdf (resposta sem PDF, como a de código que não existe), limite_de_requisicoes (o serviço recusou o pedido; basta pedir de novo as linhas que falharam), entrada_invalida (código que não é inteiro nem texto só de dígitos, como a célula vazia; nada é pedido), erro_de_gravacao (o PDF chegou, mas não pôde ser gravado: disco cheio, pasta sem permissão) ou um motivo de rede de MOTIVOS_FALHA. As falhas saem também num único UserWarning ao fim.

Exemplo

>>> import juscraper as jus
>>> tse = jus.scraper("tse")
>>> baixados = tse.baixar_inteiros_teores([2972172, 3522031])

listar_classes

courts.tse.client.TSEScraper.listar_classes(tribunal='tse')

Lista as classes processuais do formulário de jurisprudência do TSE ou dos TREs.

Parameters

Name Type Description Default
tribunal str "tse" (default), um TRE ("tre-sp") ou "tres", os 27 TREs juntos. Vale o mesmo nos demais listar_*. 'tse'

Raises

Name Type Description
ValueError tribunal desconhecido, antes de qualquer pedido.

Returns

Name Type Description
pd.DataFrame Colunas sigla_classe e descricao_classe, como o portal as devolve. A mesma descrição aparece com mais de uma sigla (RESPE e REspEl, por exemplo).

Exemplo

>>> import juscraper as jus
>>> tse = jus.scraper("tse")
>>> classes = tse.listar_classes()
>>> classes_tre_sp = tse.listar_classes(tribunal="tre-sp")
