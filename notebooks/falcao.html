Falcao — National Labor-Justice Jurisprudence (CSJT)

FalcaoScraper queries the Jurisprudencia Nacional system of the Brazilian Labor Justice (Justica do Trabalho), hosted by the CSJT at https://jurisprudencia.jt.jus.br. A single search endpoint spans the TST and all 24 TRTs across five document collections.

Method Description
listar_decisoes Jurisprudence search — returns a DataFrame
listar_decisoes_download Downloads the raw JSON pages to disk
listar_decisoes_parse Parses a folder produced by listar_decisoes_download

Collections (colecao argument): acordaos (default), sentencas, decisoesmonocraticas, precedentes, recursorevista.

Notes: the public (unauthenticated) endpoint only allows page sizes of 5 or 10 (tamanho_pagina) and caps results at 10,000 per query.

Basic search

This example requests two pages. Always select a bounded number of pages for exploratory queries. The backend can respond with HTTP 429 and a long wait. Increasing sleep_time does not cancel an active block.

On 2026-10-03, five successful probes, including three consecutive calls in one session, each reported x-rate-limit-remaining: 49. Later that day, HTTP 429 reported a wait of 27,720 seconds at 19:17:44 UTC, pointing to release at 23:59:44 in Brasilia. This is consistent with the earlier midnight-reset hypothesis, but the quota size and the meaning of the successful-response counter remain unverified. The client does not use that counter to reject larger searches in advance. See issue #350.

If listar_decisoes fails after receiving pages, it preserves their JSON files in their own folder under the system temporary directory; the scraper’s download_path is not used. The exception note gives the folder to pass to listar_decisoes_parse for a partial result. This does not resume the interrupted search. Successful calls remove their temporary files.

import juscraper as jus

falcao = jus.scraper("falcao")
df = falcao.listar_decisoes("dano moral", paginas=2, tamanho_pagina=10)
print(df.shape)

Using filters

Filters are validated by the InputListarDecisoesFalcao pydantic schema. Multi-value filters accept a string or a list of strings.

df_filtrado = falcao.listar_decisoes(
    "hora extra",
    paginas=1,
    tribunais=["TST", "TRT3"],       # court(s)
    ordenacao="mais_recente",         # mais_relevante | mais_recente | menos_recente
    data_juntada_inicio="2023-01-01",  # ISO or DD/MM/YYYY, filters dataJuntada
    data_juntada_fim="2023-12-31",
)
print(df_filtrado.shape)

Querying different collections

The same search works across collections; each returns its own document shape, normalized to a common core (processo, colecao, tribunal, …).

Regional precedents can use idTema instead of id. Their processo key retains that identifier with a tribunal prefix; it is not a CNJ case number.

df_sent = falcao.listar_decisoes("acidente de trabalho", paginas=1, colecao="sentencas")
print("sentencas:", df_sent.shape)

df_sum = falcao.listar_decisoes("dano moral", paginas=1, colecao="precedentes")
print("precedentes:", df_sum.shape)

Download and parse separately

Each listar_decisoes_download call creates its own subfolder and saves one raw JSON file per page (named {colecao}_{page}.json); listar_decisoes_parse reads a folder back into a DataFrame.

import tempfile, os, json

with tempfile.TemporaryDirectory() as tmp:
    pasta = falcao.listar_decisoes_download("dano moral", paginas=1, diretorio=tmp)
    arquivos = os.listdir(pasta)
    print("files:", arquivos)

    raw = json.load(open(os.path.join(pasta, arquivos[0])))
    print("quantidadeTotal:", raw["quantidadeTotal"])
    print("raw keys:", list(raw.keys()))

    df_parsed = falcao.listar_decisoes_parse(pasta)
    print("parsed:", df_parsed.shape)
